# Merchant Insight AI Engine v2.0

An advanced, production-ready FastAPI assistant built for merchant performance analytics, customer insights, and automated order categorization.

## Key Upgrades Over Basic Implementations
- **Type Safety & Validation:** Request and response validation using Pydantic v2 schemas.
- **Dynamic Intent Engine:** Smart keyword mapping with confidence scoring instead of simple `if/else` conditions.
- **Middleware & Monitoring:** Automatic request execution timing headers (`X-Process-Time`) and CORS support.
- **API Documentation:** Interactive Swagger and ReDoc integration.

## Technology Stack
- **Language:** Python 3.10+
- **Framework:** FastAPI
- **ASGI Server:** Uvicorn
- **Validation:** Pydantic
